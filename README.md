# 🦜🔗 LangChain Explorations

A hands-on repository dedicated to **learning, experimenting, and mastering LangChain components** through **practical, real-world implementations**.

This repo is not about theory — i explored 

every concept with **working code**, **clear structure**, and **incremental complexity**, making it ideal for learners and practitioners alike.

---

## 🚀 Purpose of This Repository

The goal of this repository is to:

* Understand **core LangChain components** deeply
* Build **end-to-end pipelines** using LLMs
* Learn how different components interact in real applications
* Experiment with branching, parsing, routing, and chaining logic

Each folder focuses on a specific concept with **clean, minimal, and runnable examples**.

---

## 🧩 Topics Covered

This repository explores (and will continue to explore):

* 🔹 Prompt Templates
* 🔹 LLMs & Chat Models (HuggingFace, OpenAI-style OSS models)
* 🔹 Output Parsers

  * String Output Parser
  * Pydantic Output Parser
* 🔹 Chains & LCEL (`|` operator)
* 🔹 Runnable Interfaces

  * `RunnableLambda`
  * `RunnableBranch`
  * `RunnableParallel`
* 🔹 Conditional Routing & Decision Making
* 🔹 Structured Outputs with Pydantic
* 🔹 Environment & Config Management
